# 내 단어장 (PWA)

단어장, 플래시카드, 받아쓰기, 뜻쓰기, 객관식 퀴즈가 들어 있는 개인용 웹앱입니다.
정적 파일만으로 동작하고, Firebase(무료)를 연결하면 같은 계정으로 로그인한 모든 기기에서 단어장과 학습 기록이 자동으로 맞춰집니다.
Firebase를 연결하지 않으면 지금 쓰는 기기의 브라우저에만 저장됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 전체 (화면, 스타일, 기능) |
| `manifest.webmanifest` | 홈 화면에 추가했을 때의 이름, 아이콘, 색 |
| `sw.js` | 오프라인에서도 앱이 열리게 하는 서비스 워커 |
| `firebase-config.js` | Firebase 프로젝트 설정을 붙여 넣는 곳 (처음엔 비어 있음) |
| `firebase-sync.js` | Firebase 로그인과 데이터베이스 연결부 |
| `firestore.rules` | Firebase에 붙여 넣을 보안 규칙 (올리지 않아도 되는 참고 파일) |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`, `favicon-32.png` | 앱 아이콘 (홈 화면, 안드로이드, 브라우저 탭) |

## 무료로 올리기 (GitHub Pages)

1. GitHub에서 새 저장소를 만듭니다. 예: `vocab`
2. 저장소의 **Add file → Upload files** (빈 저장소라면 **uploading an existing file** 링크)에서 **choose your files**를 누르고, 이 폴더의 파일 12개를 전부 골라 올립니다. 폴더 없이 파일만 있어서 한 번에 고를 수 있어요.
3. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `(root)`로 정하고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/vocab/` 주소로 열립니다.

Cloudflare Pages, Netlify, Vercel에 폴더째 끌어다 놓아도 똑같이 동작합니다.

## 아이폰, 아이패드에 앱처럼 설치하기

1. 사파리로 위 주소를 엽니다.
2. 공유 버튼 → **홈 화면에 추가**를 누릅니다.
3. 이제부터는 홈 화면 아이콘으로 여세요. 사파리 탭과 홈 화면 앱은 저장 공간이 따로라서, 한쪽에서 입력한 단어가 다른 쪽에 보이지 않습니다.

맥은 사파리의 **파일 → Dock에 추가**로 같은 방식으로 설치할 수 있습니다.

## Firebase 연결하기 (모든 기기 동기화)

한 번만 하면 됩니다. 신용카드 없이 무료 요금제(Spark)로 충분합니다. Firebase 화면의 메뉴 이름은 시기에 따라 조금 다를 수 있어요.

### 1. 프로젝트 만들기
1. https://console.firebase.google.com 에 구글 계정으로 들어갑니다.
2. **프로젝트 추가(만들기)** → 이름은 아무거나(예: `my-vocab`). Google 애널리틱스는 꺼도 됩니다.

### 2. 이메일 로그인 켜기
1. 왼쪽 **빌드 → Authentication → 시작하기**
2. **로그인 방법** 탭 → **이메일/비밀번호** → 사용 설정 → 저장 (아래 '이메일 링크'는 켜지 않아도 됩니다)
3. **설정** 탭 → **승인된 도메인**에 앱 주소의 도메인을 추가합니다. 예: `아이디.github.io`

### 3. 데이터베이스 만들기
1. 왼쪽 **빌드 → Firestore Database → 데이터베이스 만들기**
2. 위치는 `asia-northeast3 (서울)`을 고르고, **프로덕션 모드**로 시작합니다.
3. 만든 뒤 **규칙** 탭에서 내용을 모두 지우고 `firestore.rules` 파일 내용을 붙여 넣은 다음 **게시**를 누릅니다.
   이 규칙은 로그인한 사람이 자기 단어장만 읽고 쓸 수 있게 합니다.

### 4. 설정값을 앱에 넣기
1. 왼쪽 위 톱니바퀴 → **프로젝트 설정 → 일반** → 아래 **내 앱**에서 웹 아이콘(`</>`)을 누릅니다.
2. 앱 닉네임을 적고 **앱 등록** (Firebase 호스팅은 체크하지 않아도 됩니다).
3. 화면에 나오는 `firebaseConfig = { ... }` 안의 값을 `firebase-config.js`에 붙여 넣습니다.
   파일 안에 예시가 있으니 그 모양대로 바꾸고, `window.VOCAB_FIREBASE_CONFIG = null;` 줄은 지우세요.
   이 값은 비밀번호가 아니라서 공개 저장소에 올려도 괜찮습니다.
4. 바뀐 `firebase-config.js`를 GitHub 저장소에 올립니다. (GitHub 웹에서 파일을 열고 연필 아이콘으로 고쳐도 됩니다)

### 5. 로그인
1. 첫 기기에서 앱을 열고 **설정 → 모든 기기 동기화**에서 이메일과 비밀번호를 적고 **계정 만들기**를 누릅니다.
   이 기기에 있던 단어가 계정에 올라갑니다.
2. 다른 기기에서는 같은 이메일로 **로그인**합니다.
   그 기기에도 단어가 있으면 **합치기**와 **계정 것만 쓰기** 중에 고르라고 물어봅니다.
   예시 단어장만 있던 기기라면 **계정 것만 쓰기**를 고르면 됩니다.
3. 오른쪽 위 톱니바퀴에 초록 점이 보이면 동기화된 상태입니다.

### 6. (선택) 다른 사람이 계정을 못 만들게 하기
앱 주소를 아는 사람은 계정을 만들 수 있습니다. 보안 규칙 때문에 내 단어장은 볼 수 없지만, 무료 사용량을 나눠 쓰게 됩니다.
내 계정을 만든 뒤 **Authentication → 설정 → 사용자 작업**에서 **생성(가입) 사용 설정**을 끄면 새 계정을 만들 수 없습니다.

## 동기화는 이렇게 동작해요

- 단어 하나, 단어장 하나가 각각 서버의 문서 하나입니다. 바뀐 것만 올라가고, 다른 기기의 변경은 몇 초 안에 들어옵니다.
- 인터넷이 끊겨도 평소처럼 쓸 수 있습니다. 바뀐 내용은 기기에 쌓였다가 연결되면 자동으로 올라갑니다.
- 두 기기에서 같은 단어를 동시에 고치면 나중에 서버에 닿은 쪽이 남습니다.
- 무료 요금제 한도는 하루 읽기 5만 번, 쓰기 2만 번, 저장 1GB입니다. 혼자 쓰면 넉넉합니다.
  (단어를 한 번 맞히거나 틀릴 때마다 쓰기 1번, 앱을 처음 열 때 단어 수만큼 읽기)
- 로그아웃해도 이 기기의 단어는 남아 있고, 다시 로그인하면 계정과 합칠 수 있습니다.
- **설정 → 백업과 옮기기**로 따로 보관해 둘 수도 있습니다. 로그인한 상태에서 백업을 불러오면 모든 기기의 단어장이 백업 내용으로 바뀝니다.

## 뜻 자동 채우기

단어만 입력하면 뜻을 찾아 채워 줍니다. 단어장마다 언어(영어, 크로아티아어 등)를 정해 두면 그 언어로 찾습니다.

- 단어장 화면 오른쪽 위 **+** 버튼으로 추가 창을 엽니다.
- **하나씩 추가**: 단어를 입력하고 잠깐 멈추면 뜻이 채워지고, 다른 뜻 후보가 버튼으로 나옵니다. 버튼을 눌러 뜻에 넣거나 뺄 수 있어요.
- 엔터나 탭을 누르면 단어 → 뜻 → 예문 → 추가 순서로 바로 넘어갑니다.
- **여러 개 한 번에 추가**: 한 줄에 단어만 적으면 뜻을 찾아 채웁니다. 못 찾은 단어는 입력칸에 남겨 둡니다.
- 영어 단어는 예문과 품사도 함께 채웁니다(dictionaryapi.dev).
- 번역은 무료 번역 API인 MyMemory를 씁니다. 하루 5,000자(단어 수백 개)까지 무료이고, 기계 번역이라 가끔 어색한 뜻이 나올 수 있어요.
- 한도를 늘리고 싶다면 `index.html`에서 `api.mymemory.translated.net/get?` 주소 끝에 `&de=내이메일@example.com`을 붙이면 하루 50,000자로 늘어납니다.

## CSV 파일 불러오기

엑셀, 구글 시트, Anki 등에서 내보낸 CSV(또는 탭 구분 TXT)를 단어장으로 넣을 수 있습니다.

- **새 단어장 → CSV 파일로 만들기**, **설정 → CSV 파일 불러오기**, 또는 단어 추가 창의 **여러 개 → CSV 파일에서 불러오기**
- 새 단어장으로 만들거나 기존 단어장에 추가할 수 있습니다. 단어·뜻·예문이 몇 번째 열인지 고르고 미리보기로 확인한 뒤 넣습니다.
- 첫 줄에 `단어, 뜻, 예문`(또는 `word, meaning, example`) 같은 제목이 있으면 알아서 열을 맞춥니다.
- 쉼표, 세미콜론, 탭 구분 모두 읽고, 한국어 윈도우 엑셀에서 저장한 CSV도 글자가 깨지지 않게 읽습니다.
- 뜻 열이 없거나 비어 있으면 자동 번역으로 채울 수 있습니다. 파일 안 중복과 기존 단어장에 이미 있는 단어는 빼고 넣습니다.

예시:

```
단어,뜻,예문
kuća,집,Moja kuća je velika.
putovati,"여행하다, 여행가다",Volim putovati.
```

## 크로아티아어, 세르비아어

- 단어 추가와 받아쓰기 화면에 č ć đ š ž 입력 버튼이 나옵니다(세르비아어는 라틴 문자 기준).
- 받아쓰기에서 부호만 빠뜨린 답(kuca → kuća)은 정답으로 치고 따로 알려 줍니다.
- 발음이 영어처럼 들리면 아이폰 **설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성**에서 크로아티아어 음성을 내려받아 주세요.
- 세르비아어 음성이 없는 기기에서는 발음이 거의 같은 크로아티아어 음성으로 읽습니다.

## 수정해서 다시 올릴 때

`sw.js` 맨 위의 `CACHE = 'vocab-v12'`를 `vocab-v13`처럼 올려야 기기에 새 버전이 반영됩니다.
홈 화면 앱은 완전히 닫았다가 다시 열면 업데이트됩니다.

## 학습 방식 (레이트너 상자)

단어마다 0~6번 상자가 있습니다. 플래시카드, 받아쓰기, 뜻쓰기, 퀴즈 어디서든 맞히면 다음 상자로 옮겨가고,
틀리면 0번 상자로 돌아가 오늘 다시 복습 목록에 올라옵니다.

| 상자 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 다음 복습 | 오늘 | 1일 후 | 2일 후 | 4일 후 | 7일 후 | 15일 후 | 30일 후 |

간격은 `index.html`의 `INTERVALS` 배열에서 바꿀 수 있습니다.
